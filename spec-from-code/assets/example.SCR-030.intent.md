# SCR-030 プロフィール編集画面 意図メモ

- 画面を開いたとき、保存済みの値を各入力欄に表示すること
- 表示名が未入力または空白のみの場合、「表示名を入力してください」と表示すること
- 表示名が50文字を超える場合、「表示名は50文字以内で入力してください」と表示すること
- もしメールアドレスが他の利用者と重複している場合、「このメールアドレスは既に使用されています」と表示すること
- 保存処理の間、保存ボタンは押せないこと
- 保存に成功したとき、「保存しました」と通知し、通知は3秒後に自動で消えること
- もし他の利用者が先に更新していた場合、上書きせずに最新の取得を促すこと
